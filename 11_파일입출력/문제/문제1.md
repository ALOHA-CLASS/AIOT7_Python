# **문제 1. TodoList 일정 및 할 일 관리 프로그램**

일상생활에서 해야 할 일을 등록하고, 완료 여부를 관리하는 TodoList 프로그램을 작성하세요.

### **문제 설명**

사용자는 할 일을 등록하고, 완료 처리하거나 삭제할 수 있습니다.

각 할 일은 다음 정보를 가지고 있습니다.

- 할 일 번호
- 할 일 제목
- 마감일
- 완료 여부
- 중요도

일반 할 일과 중요 할 일로 구분하여 관리하며, 프로그램을 종료하더라도 할 일 목록이 유지되도록 파일에 저장해야 합니다.

### **요구사항**

**클래스 설계**

- `Todo` 클래스 : 일반 할 일을 관리합니다.
  - `id` : 할 일 번호
  - `title` : 할 일 제목
  - `due_date` : 마감일
  - `completed` : 완료 여부
  - `complete()` : 할 일을 완료 처리합니다.
  - `__str__()` : 할 일 정보를 출력합니다.
- `ImportantTodo` 클래스 : 중요 할 일을 관리합니다.
  - `Todo` 클래스를 상속받습니다.
  - `priority` : 중요도 (높음, 보통, 낮음)
  - `__str__()` : 중요도 정보를 포함하여 출력합니다.

**할 일 관리**

다음 기능을 구현합니다.

- `add_todo()` : 새로운 할 일을 등록합니다.
- `show_todos()` : 전체 할 일 목록을 출력합니다.
- `complete_todo(todo_id)` : 선택한 할 일을 완료 처리합니다.
- `delete_todo(todo_id)` : 선택한 할 일을 삭제합니다.
- `show_incomplete_todos()` : 완료하지 않은 할 일만 출력합니다.

**예외처리**

다음 상황에서 예외처리를 수행합니다.

- 숫자가 아닌 할 일 번호를 입력한 경우
- 존재하지 않는 할 일 번호를 선택한 경우
- 빈 제목을 입력한 경우
- 잘못된 날짜 형식을 입력한 경우
- 파일이 존재하지 않는 경우

**모듈 분리**

```
todo_app/
│
├── main.py
├── todo.py
├── manager.py
└── todos.json
```

- `todo.py` : Todo, ImportantTodo 클래스 정의
- `manager.py` : TodoManager 클래스 및 할 일 관리 기능
- `main.py` : 사용자 입력 및 메뉴 실행
- `todos.json` : 할 일 목록 저장 파일

**파일 입출력**

- `save_todos()` : 할 일 목록을 JSON 파일에 저장합니다.
- `load_todos()` : JSON 파일에서 할 일 목록을 불러옵니다.
- 프로그램 실행 시 기존 할 일 목록을 불러옵니다.
- 할 일이 추가, 수정, 삭제될 때 파일에 저장합니다.

### **실행 예시**

```
========== TODO LIST ==========

1. 할 일 등록
2. 전체 할 일 조회
3. 할 일 완료
4. 할 일 삭제
5. 미완료 할 일 조회
6. 프로그램 종료

메뉴 선택: 1

할 일 제목: 파이썬 공부하기
마감일 (YYYY-MM-DD): 2026-11-30
중요 할 일인가요? (y/n): y
중요도 (높음/보통/낮음): 높음

할 일이 등록되었습니다.

========== TODO LIST ==========

1. 할 일 등록
2. 전체 할 일 조회
3. 할 일 완료
4. 할 일 삭제
5. 미완료 할 일 조회
6. 프로그램 종료

메뉴 선택: 2

[1] 파이썬 공부하기
    마감일: 2026-11-30
    상태: 진행 중
    중요도: 높음

[2] 운동하기
    마감일: 2026-11-28
    상태: 완료
```
