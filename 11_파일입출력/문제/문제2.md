# **문제 2. 프로그램 바로 실행 런처 (Program Launcher)**

컴퓨터에 설치된 프로그램을 번호로 선택하여 바로 실행할 수 있는 프로그램 런처를 작성하세요.

### **문제 설명**

사용자가 자주 사용하는 프로그램의 이름과 실행 파일 경로를 등록하고, 번호를 입력하면 해당 프로그램을 실행하는 프로그램을 작성하세요.

예를 들어 다음과 같이 프로그램 목록을 관리합니다.

| 번호 | 프로그램명              | 실행 파일 경로                                                        |
| -- | ------------------ | --------------------------------------------------------------- |
| 1  | 메모장                | C:\Windows\System32\notepad.exe                                 |
| 2  | 계산기                | C:\Windows\System32\calc.exe                                    |
| 3  | 그림판                | C:\Windows\System32\mspaint.exe                                 |
| 4  | Visual Studio Code | C:\Users\User\AppData\Local\Programs\Microsoft VS Code\Code.exe |
| 5  | 크롬                 | C:\Program Files\Google\Chrome\Application\chrome.exe           |

사용자는 프로그램 번호를 입력하여 원하는 프로그램을 실행할 수 있습니다.

등록된 프로그램 목록은 파일에 저장하여 다음 실행 시에도 유지되어야 합니다.

### **요구사항**

**클래스 설계**

- `Program` 클래스 : 실행할 프로그램 정보를 관리합니다.
  - `id` : 프로그램 번호
  - `name` : 프로그램 이름
  - `path` : 실행 파일 경로
  - `__str__()` : 프로그램 정보를 출력합니다.
- `Launcher` 클래스 : 프로그램 목록과 실행 기능을 관리합니다.
  - `programs` : 등록된 프로그램 목록
  - `add_program()` : 프로그램을 등록합니다.
  - `show_programs()` : 프로그램 목록을 출력합니다.
  - `run_program(program_id)` : 선택한 프로그램을 실행합니다.
  - `delete_program(program_id)` : 등록된 프로그램을 삭제합니다.

**상속**

- `Program` 클래스를 상속받는 `ShortcutProgram` 클래스를 구현합니다.
- `ShortcutProgram`은 프로그램 이름과 실행 경로 외에 `category` 속성을 추가합니다.
- `__str__()` 메서드를 오버라이딩하여 카테고리도 출력합니다.

**예외처리**

다음 상황에서 예외처리를 수행합니다.

- 숫자가 아닌 프로그램 번호를 입력한 경우
- 존재하지 않는 프로그램 번호를 선택한 경우
- 실행 파일 경로가 존재하지 않는 경우
- 잘못된 파일 형식을 불러오는 경우
- 프로그램 실행 중 오류가 발생한 경우

**파일 입출력**

프로그램 목록을 `programs.json` 파일에 저장하고 불러옵니다.

- `save_programs()` : 등록된 프로그램을 JSON 파일에 저장합니다.
- `load_programs()` : JSON 파일에서 프로그램 목록을 불러옵니다.

### **스켈레톤 코드 제공**

프로그램 실행 기능에 필요한 외부 모듈은 스켈레톤 코드로 제공합니다.

학생들은 제공된 코드를 참고하여 클래스와 메뉴 기능을 완성합니다.

**① launcher_skeleton.py**

```
# 프로그램 실행에 필요한 모듈import osimport subprocess# 프로그램 실행 함수def execute_program(path):    # 실행 파일 경로가 존재하는지 확인    if not os.path.exists(path):        print("실행 파일을 찾을 수 없습니다.")        return    try:        # 프로그램 실행        subprocess.Popen([path])        print("프로그램을 실행했습니다.")    except Exception as e:        print("프로그램 실행 중 오류가 발생했습니다.")        print(e)
```

**② 프로그램 실행 모듈 사용 방법**

```
from launcher_skeleton import execute_program# 실행할 프로그램 경로path = r"C:\Windows\System32\notepad.exe"# 프로그램 실행execute_program(path)
```

> `os`, `subprocess` 모듈은 별도로 학습하지 않아도 됩니다. 제공된 스켈레톤 코드를 import하여 사용하세요.

### **실행 예시**

```
=================================
       PROGRAM LAUNCHER
=================================

[ 프로그램 목록 ]

1. 메모장
2. 계산기
3. 그림판
4. Visual Studio Code
5. 크롬

=================================
6. 프로그램 등록
7. 프로그램 삭제
8. 프로그램 목록 저장
0. 프로그램 종료
=================================

실행할 프로그램 번호: 1

[메모장] 프로그램을 실행했습니다.
```

**프로그램 등록 예시**

```
프로그램 이름: 카카오톡
실행 파일 경로: C:\Program Files (x86)\Kakao\KakaoTalk\KakaoTalk.exe

프로그램이 등록되었습니다.
```

**프로그램 삭제 예시**

```
삭제할 프로그램 번호: 3

[그림판] 프로그램을 삭제했습니다.
```
