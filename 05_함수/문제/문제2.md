## **문제 2. 편의점 재고 및 매출 관리 시스템**

편의점의 상품 재고를 관리하고, 고객의 구매 요청에 따라 재고를 차감하고 매출을 계산하는 프로그램을 작성하세요.

### **문제 설명**

편의점에는 여러 상품이 등록되어 있으며, 각 상품은 상품명, 가격, 재고 수량으로 구성됩니다.

다음과 같이 딕셔너리로 상품 정보를 관리합니다.

```
products = {    
  "사과": {"price": 1500, "stock": 10},
  "우유": {"price": 2500, "stock": 5},
  "라면": {"price": 1200, "stock": 20},
  "빵": {"price": 2000, "stock": 8},
  "콜라": {"price": 1800, "stock": 12}
}
```

고객이 구매할 상품과 수량을 입력하면 상품의 존재 여부와 재고를 확인하고, 구매 가능한 상품만 결제 처리해야 합니다.

### **요구사항**

**상품 관리**

- `show_products(products)` : 전체 상품명, 가격, 재고를 출력합니다.
- `check_product(products, name)` : 상품이 등록되어 있는지 확인합니다.
- `check_stock(products, name, quantity)` : 요청한 수량만큼 재고가 있는지 확인합니다.
- `update_stock(products, name, quantity)` : 구매한 수량만큼 재고를 차감합니다.

**주문 처리**

- `calculate_total(products, order)` : 주문 상품들의 총금액을 계산합니다.
- `calculate_discount(total)` : 구매 금액에 따른 할인율을 반환합니다.

| 구매 금액      | 할인율 |
| ---------- | --- |
| 50,000원 이상 | 10% |
| 30,000원 이상 | 5%  |
| 10,000원 이상 | 2%  |
| 10,000원 미만 | 0%  |

\- `process_order(products, order)` : 주문 전체를 처리하는 메인 함수입니다.

**주문 데이터 예시**

```
order = {    
  "사과": 3,    
  "우유": 2,    
  "라면": 5,    
  "콜라": 2
}
```

**처리 조건**

- 등록되지 않은 상품은 구매할 수 없습니다.
- 재고가 부족한 상품은 구매할 수 없습니다.
- 하나라도 구매할 수 없는 상품이 있다면 전체 주문을 취소합니다.
- 모든 상품의 구매가 가능하면 총금액을 계산합니다.
- 할인율을 적용하여 최종 결제 금액을 계산합니다.
- 결제가 완료되면 모든 상품의 재고를 차감합니다.
- 주문 처리 결과와 최종 결제 금액을 반환합니다.

### **실행 예시**

```
result = process_order(products, order)

if result:    
  print("주문이 완료되었습니다.")    
  print(f"주문 금액: {result['total']:,}원")    
  print(f"할인 금액: {result['discount']:,}원")    
  print(f"최종 결제 금액: {result['payment']:,}원")
  show_products(products)
```
